### Modifications à apporter à routes/api.php

1) Ajouter l'import en haut du fichier :
use App\Http\Controllers\BictorysController;

2) Route PUBLIQUE (hors middleware auth:sanctum) — Bictorys appelle ceci
   directement depuis leurs serveurs, sans session utilisateur, donc
   auth:sanctum la bloquerait à tort. À placer au même niveau que
   /register, /login, /forgotPassword :

    Route::post('/webhooks/bictorys', [BictorysController::class, 'webhook']);

3) Route PROTÉGÉE — à ajouter DANS le groupe middleware('auth:sanctum'),
   au même niveau que les routes /paiements existantes (accessible à tout
   utilisateur connecté, pas seulement admin/formateur, puisque c'est
   l'étudiant qui paie sa propre inscription) :

    Route::post('/paiements/{paiement}/bictorys', [BictorysController::class, 'initiate']);

Résultat attendu (extrait) :

    Route::post('/webhooks/bictorys', [BictorysController::class, 'webhook']);

    Route::middleware('auth:sanctum')->group(function () {
        // ... routes existantes ...

        Route::apiResource('paiements', PaiementController::class);
        Route::post('/paiements/{paiement}/bictorys', [BictorysController::class, 'initiate']);

        // ... reste des routes existantes ...
    });

        'public_key' => env('BICTORYS_PUBLIC_KEY'),
        'webhook_secret' => env('BICTORYS_WEBHOOK_SECRET'),
    ],

### Dashboard Bictorys — configuration du webhook

Dans dashboard.bictorys.com > Développeurs > Webhooks, configure l'URL :
    https://api.2i-online.com/api/v1/webhooks/bictorys
(à adapter selon le vrai chemin monté par ton app — vérifie le préfixe
exact avec `php artisan route:list --path=webhooks`)
Puis copie la "clé secrète du webhook" affichée dans BICTORYS_WEBHOOK_SECRET.
